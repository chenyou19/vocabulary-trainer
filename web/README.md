# Vocabulary Trainer

繁體中文的個人英文單字網站。React、TypeScript 和 Vite 編譯成可由 GitHub Pages 提供的靜態網站。單字、進度、作答紀錄及設定都存放在目前瀏覽器的 IndexedDB。

## 本機啟動

安裝 Node.js 24。建議使用專案指定的 pnpm 11.25.0，依鎖檔安裝相同版本的套件。從存放庫根目錄執行以下指令，再開啟 Vite 顯示的本機網址。

```sh
cd web
pnpm install --frozen-lockfile
pnpm dev
```

Windows PowerShell 若阻擋 pnpm 的指令碼，可以用 `pnpm.cmd` 執行相同指令。

也可以在剛取得的工作副本中用 npm 安裝與啟動。這個方式會依 `package.json` 選擇依賴版本。

```sh
cd web
npm install
npm run dev
```

## 使用方式

- 首次在全新的瀏覽器資料庫開啟網站時，會自動下載並儲存專案 TOEIC 詞庫，可直接開始練習。這次下載需要網路連線，失敗時可從畫面重試。
- 原有單字、學習紀錄或設定的資料庫會保留現況。確認清除資料或還原備份後，重新開啟時會維持清除或還原的結果。
- 在單字庫手動新增、編輯、刪除、搜尋或篩選單字，也可批次匯入 JSON、CSV 或手動匯入專案 TOEIC 詞庫。從單字庫下載 CSV 範例可取得支援的欄名。批次匯入會預覽可匯入、重複與無效的項目。
- 單字庫依來源星級分組，每組最多 50 個單字。選好星級和組別後，可用「背這組」或「測驗這組」帶入相同範圍。星級採用原詞庫的編排標記，作為安排背誦先後的參考。無星級的單字保留在「未分級」。
- 單字卡的「今日練習」先排已學且到期的單字，再依來源星級由高到低排新字。也能只複習到期字，或手動練習所選範圍的全部單字。卡片支援英翻中、中翻英、英文發音與三種記憶評分，後續複習日依瀏覽器本地日期計算。
- 測驗可調整題數、星級、分組及分類，也能集中練習錯題。選擇題從所選範圍找四個互異且適合當題的選項。選項不足時，可以擴大範圍或改用拼字模式。
- 首頁和學習統計根據實際作答與複習紀錄計算。同一天練習同一單字多次，當日學習量計一次。當日測驗正確率以當日測驗作答計算。
- 設定頁可調整每日目標、主題，並下載含版本、進度與紀錄的完整 JSON 備份。單字庫匯出的 JSON 適合搬移單字。若要保留學習進度，請使用設定頁的完整備份。

同一瀏覽器設定檔、同一網站來源下，重新整理會保留已儲存的單字、進度及作答。更換網域、連接埠、瀏覽器設定檔或裝置時，可透過完整 JSON 備份移轉資料。瀏覽器若封鎖 IndexedDB 或清除網站資料，原有紀錄可能無法存取。發音僅使用瀏覽器標示為本機的英語語音，預設優先使用 `en-US`。若找不到可用的本機英語語音，發音按鈕會提示原因。

## 開發與驗證

在 `web/` 執行以下指令。`pnpm build` 也可執行同一份正式建置。

```sh
pnpm lint
pnpm typecheck
pnpm test
npm run build
pnpm test:path
pnpm preview
```

| 路徑 | 用途 |
| --- | --- |
| `src/domain/` | 本地日期、SRS、測驗、匯入驗證和統計 |
| `src/data/` | Dexie 資料表和 IndexedDB 交易 |
| `src/` | 頁面、共用元件、導覽和樣式 |
| `tests/` | Vitest 單元測試及使用 IndexedDB 模擬的整合測試 |
| `scripts/check-pages.mjs` | 驗證正式建置的資源可從根路徑及專案子路徑解析 |

在 Windows、Node.js 24 和 npm 11 下通過 ESLint、TypeScript、54 項 Vitest 測試、`npm run build` 及兩種部署路徑檢查。回歸測試涵蓋首次載入、舊資料庫升級、清除與還原、完整詞庫分組、到期字優先，以及所選組別內的測驗範圍。

GitHub Actions 的 Linux 環境已通過全新安裝 `pnpm install --frozen-lockfile`，也完成 lint、32 項測試、正式建置與兩種部署路徑檢查。先前的 `EPERM` 出現在 Windows exFAT 磁碟上的額外離線重裝測試。本機檢查使用已安裝的依賴完成。[首次部署工作流程](https://github.com/chenyou19/vocabulary-trainer/actions/runs/42785448280)

TOEIC 詞庫來源為存放庫根目錄的 `toeic_vocabulary.json`。開發與建置時請保留它與 `web/` 的相對位置。目前詞庫有 11,238 筆原始條目，正規化後有 11,154 個不同詞頭。相同詞頭會合併成一張單字卡，各筆原始資料會保留在該卡的來源資料中。約 22.6 MB 的詞庫檔案獨立於網站程式，首次使用全新資料庫或手動選擇匯入時才會下載。

同詞頭採來源中的最高合法星級，並在各星級內依正規化的詞頭排序分組。完整詞庫有 5 星 54 組、4 星 72 組、3 星 55 組、2 星 25 組及 1 星 20 組。練習進度、搜尋和分類篩選皆沿用已計算的組別。編輯詞頭、變更來源星級、刪除或新增單字時，組別會依詞庫重新計算，學習紀錄仍跟隨原本的單字。

### 瀏覽器驗收

以下結果來自本機驗收用的瀏覽器資料庫，與使用者的學習紀錄分開。

- 桌面和 390 px 手機寬度的版面均通過視覺檢查。空單字庫的測驗頁顯示新增或匯入提示。
- 全新資料庫首次開啟即自動載入 11,154 個單字，重新整理後數量相同。既有資料庫升級後，單字、學習進度、統計與每日目標均保留。手動匯入專案詞庫也已驗證。
- 中翻英單字卡在翻面前只顯示中文，翻面後才顯示英文及發音按鈕。提交記憶評分後，複習階段與下次複習日期更新。
- 完成 5 題英翻中測驗，答對 4 題、答錯 1 題。重練該題時因選項不足而自動切換拼字，接受前後各含兩個空白的 `BRANCHES`。重新整理後，統計仍顯示 6 題答對 5 題，正確率為 83%。
- 深淺主題與每日目標可保存。下載完整備份後重新上傳，成功還原 11,154 個單字、7 筆練習紀錄和 2 次測驗。清除資料時會要求輸入確認文字，也可取消操作。
- 已驗證缺少本機英語語音時會顯示提示。實際語音播放待有本機英語語音的裝置驗證。

## GitHub Pages 部署

網站和發布原始碼可從這兩個連結開啟。[Vocabulary Trainer 網站](https://chenyou19.github.io/vocabulary-trainer/) · [GitHub 存放庫](https://github.com/chenyou19/vocabulary-trainer)

1. 將網站所需的檔案放進 GitHub 存放庫，保留目前的目錄結構。網站使用 `web/` 的原始碼、根目錄的 `toeic_vocabulary.json` 和 `.github/workflows/vocabulary-pages.yml`。
2. 在存放庫的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。[GitHub Pages 官方設定說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
3. 推送網站相關變更至預設分支，或在 **Actions → Deploy Vocabulary Trainer to GitHub Pages** 選擇預設分支並手動執行。成功時可從部署工作開啟網站。

工作流程先檢查程式、執行測試及建置，再部署 `web/dist`。Vite 使用相對資源路徑，React Router 使用 HashRouter。專案頁面可從 `https://<帳號>.github.io/<存放庫>/#/quiz` 開啟及重新整理。存放庫改名時通常不需修改建置設定。

## 使用限制與擴充方向

- 選擇題依中文定義及來源資料中的文字義項排除可能同義的選項。文字差異較大的近義詞仍可能需要人工檢查。
- 單字卡的記憶評分負責固定間隔 SRS 排程。測驗作答會更新對錯次數與測驗紀錄，複習階段和下次複習日由單字卡評分決定。
- 重新整理會結束當下的作答流程。已儲存的答案保留並計入統計，下一輪需從測驗設定重新開始。

後續可加入進階排程演算法或更細的分類練習統計。
